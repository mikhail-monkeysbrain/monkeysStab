## Запуск рабочего состояния

Из корня репозитория:

    cd /home/vio/Desktop/monkeysStab

    export MONKEYS_LOCAL_GUI=0
    export MONKEYS_WEB_TELEMETRY_UDP_PORT=8766

    bash scripts/run_web.sh

Ожидается запуск:

- Web UI на порту 8080;
- MAVLink router;
- flight runtime;
- OV9281;
- TF-Luna;
- передача optical flow в FC.

Остановка:

    Ctrl+C

Не запускать одновременно второй экземпляр runtime, так как камера
OV9281 может быть занята.

## Ручной тест A→B

1. Запустить систему через scripts/run_web.sh.
2. Оставить аппарат неподвижным в точке A несколько секунд.
3. Один раз вручную переместить аппарат A→B.
4. Оставить аппарат неподвижным в точке B несколько секунд.
5. Остановить runtime через Ctrl+C.
6. Зафиксировать физическое расстояние A→B независимо от расчёта.
7. Для слепого теста сначала вычислить WORKED5, и только после этого
   раскрывать физический GT.

Возврат B→A для проверки масштаба не требуется.

## Где находятся результаты

Прогоны сохраняются в:

    /home/vio/monkeysStab_runs/YYYYMMDD_HHMMSS_OPTICAL_FLOW/

Основной CSV:

    optical_flow_mavlink.csv

Основные поля WORKED5:

    worked5_valid
    worked5_acc_n_m
    worked5_acc_e_m
    worked5_dN_m
    worked5_dE_m

Основные поля FC EKF3:

    ekf_local_valid
    ekf_x_ned
    ekf_y_ned
    ekf_z_ned
    ekf_vx_ned
    ekf_vy_ned
    ekf_vz_ned

Дистанция между двумя устойчивыми положениями:

    distance = sqrt((N_B-N_A)^2 + (E_B-E_A)^2)

Для корректного сравнения WORKED5 и EKF3 использовать одни и те же
временные окна A и B.

## Важное состояние исходников

В этом frozen-состоянии диагностические блоки

    WORKED5_MAG_SHADOW_V1
    DELTAR_ROTATION_SHADOW_V1

отключены PERF A/B guard'ами.

Это часть именно протестированного состояния. Не включать их при
воспроизведении frozen-результата без отдельного A/B-теста.

Сам worked5_estimator.hpp во время расследования регрессии не менялся.

## Известное ограничение

Во время некоторых запусков наблюдалась деградация обработки камеры:

    dqbuf       ~100.9 Hz
    selected    ~77.7 Hz
    dropped     ~23.2 Hz
    WORKED5     ~77.6 Hz

Несмотря на это, RUN 20260924_103724_OPTICAL_FLOW дал:

    GT       = 485.000 мм
    WORKED5  = 491.569 мм
    ошибка   = +1.35%

Поэтому потеря кадров сама по себе не подтверждена как причина ранее
наблюдавшейся ошибки масштаба WORKED5 +15...18%.

Причина интермиттирующей деградации производительности остаётся
отдельной диагностической задачей.
