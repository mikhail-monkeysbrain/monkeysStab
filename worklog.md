## Что уже исключено или существенно ослаблено

### Простая гипотеза 120 FPS / 8 ms

Был проведён cadence A/B:
- DIV1: обработка каждого кадра, blind 440 -> 434.84 мм, ошибка около -1.17%;
- DIV2: обработка каждого второго кадра, blind 470 -> 320.46 мм, ошибка около -31.82%.

DIV2 оказался конфаундирован пропущенными visual intervals/reason90 и reason5, поэтому его нельзя трактовать как доказательство, что 16 ms хуже. Но результат опровергает простую идею «достаточно перейти с ~8 ms на ~16 ms, чтобы вернуть масштаб».

DIV1 patch при `MONKEYS_WORKED5_CADENCE_DIV=1` проверен по source diff: `worked5_cadence_process` всегда true, `estimateRawFlow()` вызывается каждый кадр, anchor обновляется каждый кадр, reason90 недостижим. Поэтому DIV1 функционально соответствует исходной cadence-политике frozen WORKED5.

### Height / metric conversion

В предыдущем сравнении отношение metric/normalized displacement отличалось примерно на доли процента, тогда как BAD478 теряет около 10%. Основная потеря возникает раньше окончательного преобразования в метры.

### Direction cancellation

BAD478 path sum около 431.10 мм против vector около 429.50 мм. Следовательно, десятки миллиметров не теряются из-за поворота итогового N/E-вектора.

## Важное различие: компас/IMU и image rotation

Компас не решает эту проблему автоматически.

Компас/attitude определяют ориентацию аппарата в мире и позволяют преобразовать локальный displacement камеры в N/E.

Внутренний rotation-параметр visual fit — другое: модель по correspondences сама решает, какая часть движения изображения является translation, scale и rotation. Если она до преобразования в N/E ошибочно отдала часть настоящего translation в rotation/scale, компас потерянную длину уже не восстановит.

## Перспективное решение: IMU ΔR

Между двумя соседними кадрами реальное изменение ориентации можно брать из IMU:

`DeltaR = R(t1) * R(t0)^-1`.

Для короткого интервала между кадрами основной источник относительного угла — gyro/IMU. Компас полезен как долгосрочная абсолютная yaw-опора.

Идея: не заставлять visual fit самостоятельно угадывать вращение. По IMU ΔR предсказать/удалить rotational image motion, после чего по оставшемуся движению точек оценивать translation.

Нужно учитывать lever arm: камера не совпадает с центром IMU. При вращении камера получает реальное линейное движение `omega x r`. Нельзя просто вычесть всё вращательное optical-flow движение без геометрии camera-to-IMU.

## Предопределённый следующий причинный эксперимент

Не менять production WORKED5. Добавить только shadow-расчёты на тех же production RANSAC correspondences:

A. Frozen WORKED5 4-param — текущий production результат.

B. Translation-only shadow — те же correspondences, но без свободных scale/yaw. Желательно логировать:
- T-LS: least-squares constant translation;
- T-MED: median normalized displacement как дополнительную robust диагностику.

C. IMU-DeltaR shadow — использовать синхронизированное изменение attitude/gyro между кадрами для удаления известной rotational component, затем оценить translation. Учесть camera/IMU extrinsics и lever arm.

Все shadow arms должны:
- использовать те же кадры и те же RANSAC inliers;
- не запускать второй KLT/RANSAC;
- не менять anchor/cadence/gates;
- не влиять на MAVLink и production WORKED5;
- писать результаты только в диагностический CSV.

Интерпретация заранее фиксируется:
- A ~90%, B ~100% -> вероятно, свободные scale/yaw поглощают translation;
- A и B ~90% -> потеря уже присутствует в LK/RANSAC correspondences;
- C заметно восстанавливает GT относительно A/B -> использование измеренного IMU DeltaR перспективно;
- T-LS и T-MED сильно расходятся -> исследовать неоднородность/выбросы внутри RANSAC inlier set.

## Слепая методика

Для метрических тестов оператор не сообщает фактическое расстояние заранее.

Порядок:
1. Один горизонтальный A->B.
2. Без намеренного подъёма/наклона.
3. Зафиксировать оценки A/B/C до раскрытия GT.
4. Только после этого оператор сообщает физическое расстояние.
5. Не менять детектор/границы движения после раскрытия GT.
6. Не подгонять focal scale по одному прогону.
